# 2026-10-15 BridgeSecur frontend v2 (web/)

**What changed**: Built `web/` (React 18 + Vite 7 + TS strict + Tailwind 4 + Radix/shadcn-style UI + Framer Motion + Reown AppKit/wagmi 2 + i18next TH/EN) from UI prompt v2 (light theme, mobile-first, routes `/`, `/send`, `/consult`).

**Decisions**
- wagmi pinned to v2 (2.19.5). AppKit adapter 1.8.24 declares `@wagmi/connectors >=5.9.9`, which resolves to v8 (needs wagmi v3, fails with "Missing ./tempo specifier"). Fixed with npm `overrides` pinning `@wagmi/connectors@6.2.0` + `@wagmi/core@2.22.1`. Revisit when moving to wagmi v3.
- shadcn components are hand-written in `src/components/ui/` on top of the `radix-ui` package (no shadcn CLI).
- Pre-send alert is a sheet in our dApp, shown before the wallet is called (warn-only; Continue is never removed, on CRITICAL it needs the checkbox).
- Consult answers are templated from the check's evidence (`src/lib/consult.ts`); unknown questions get "I don't have evidence for that".

**Affected**: new `web/` folder only.
